# 智能数据分析 Agent  需求定义

## 1\. 一句话定位



对话式数据分析 Agent：上传表格，用自然语言提问，得到**可信**的数据结论。

核心差异化：**可信优先** —— 主动做数据体检、发现异常先澄清、分析过程全透明。

（对标 ChatGPT 数据分析模式的"能算"，主打它没有的"可信"。）



## 2\. 目标用户与场景



- 用户：需要数据分析但不会写代码的业务人员/学生

- 典型场景：上传销售明细 → "哪个渠道最值得砍预算？" → 得到结论 \+ 图表 \+ 依据

    

## 3\. 功能需求（按优先级）



> 注意：本节按**重要性**排列，不代表开发顺序。
> 
> 骨架 → 评测集 → 最薄端到端链路 → 本节 P0（profiler → 澄清 → 体检注入）→ P1 → P2。
> 
> 



### P0 — 数据体检（profiler）



上传数据后、用户提问前，自动输出体检报告：

- 行列数、每列类型、缺失值统计、数值列分布摘要、5 行样本

- **重复检测**：完全重复行 / 指定主键的重复，分开告警

- **脏格式检测**：数字列混杂千分位/单位等字符串

- 成功标准：在埋了脏数据的测试集上，异常检出率 100%；体检报告注入后续 prompt

    

### P0 — 对话式分析（核心链路）



- 用户提问 → 生成 pandas 代码 → 沙箱执行 → 返回结果 \+ 图表 \+ 结论

- prompt 注入体检摘要（Schema \+ 统计摘要 \+ 样本），不注入全量数据

- 成功标准：评测任务一次执行成功率 ≥ 75%

    

### P0 — 澄清机制



以下情况必须反问用户，禁止擅自决策：

- 数据异常未确认口径（如：检测到 5 条重复订单，去重与否影响结果）

- 问题模糊且有多种解读（如："分析一下这数据"→ 先展示概览并询问关注点）

- 成功标准：评测集中全部异常场景均触发澄清（异常场景召回 100%），无擅自决策；

整体触发正确率（含"不该问不问"）≥ 85%，与第 7 节指标一致



### P1 — 自修复



- 执行报错 → 格式化 traceback 回传 → 重新生成代码，最多重试 3 次

- 成功标准：配合自修复，评测任务总成功率 ≥ 90%

    

### P1 — 多轮上下文



- 支持基于之前结果的追问（"只看已完成的再算一次"）

- 维护对话状态 \+ 中间结果缓存（df 不重复加载）

    

### P1 — RAG 数据字典问答



- 用户上传可选的"数据说明文档"（或系统生成数据字典）

- 用户问业务术语/列含义时走检索（BM25 \+ 向量混合 \+ rerank）

- 成功标准：50 条术语 QA 上，引用溯源准确率 ≥ 90%

    

### P2 — 过程透明面板



- 每次回答附带：生成的代码、执行状态、引用了哪些体检结论

- Streamlit 侧边栏展示分析步骤时间线

    

## 4\. 非功能需求



- 沙箱安全：import 白名单、CPU/内存/超时限制、禁网络禁文件写入

- 流式输出：分析过程 token 级反馈

- 模型可切换：通过 litellm 统一接口（Qwen / GPT / Claude），换模型仅改配置，不改代码

- Key 策略：在线 demo 默认使用部署方 key（廉价模型），设每日调用总额度上限 \+ 单会话次数限制，

超限给出友好提示。

所有 key 从环境变量读取，禁止写入代码或仓库



## 5\. 明确不做（MVP 排除项）



- 多用户、登录、权限、多租户

- 实时数据库同步（SQLite 以文件方式接入即可）

- 图表美化、报告导出 PDF/PPT

- 多 Agent 协作、自动机器学习/预测建模

- 在线 API 数据源（Connector 接口预留，不实现）

    

## 6\. 数据源范围（MVP）



- CSV / Excel 文件上传（核心场景）

- SQLite 数据库文件接入（验证 Connector 抽象）

- 扩展方式：实现 `BaseConnector` 新增数据源（接口预留）

    

## 7\. 量化成功标准（评测）



评测集：3 个公开风格数据集（订单明细/月度销量/渠道流量）× 约 50 个任务，

含标准答案，覆盖清洗、聚合、趋势、归因、多轮五类。



|指标|目标|
|---|---|
|代码一次执行成功率|≥ 75%|
|自修复后总成功率|≥ 90%|
|数据异常检出率（profiler）|100%|
|澄清触发正确率（该问就问/不该问不问）|≥ 85%|
|RAG 术语问答准确率|≥ 90%|
